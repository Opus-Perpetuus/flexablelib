# flexablelib-speedups

Optional C acceleration for drawing terminal frames with [flexablelib](https://github.com/Opus-Perpetuus/flexablelib): visible width, cut and pad of cells, box-drawing border grids and frame diffs.

Install it with `pip install flexablelib[speed]`. flexablelib picks it up automatically and falls back to identical pure-Python code without it.

Documentation: [ACCELERATION.md](https://github.com/Opus-Perpetuus/flexablelib/blob/main/docs/ACCELERATION.md)
